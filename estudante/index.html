Sobre mim

Estudante de TI que aprende construindo

Meu nome é Vitor, sou estudante de Análise e Desenvolvimento de Sistemas e estou montando minha base na área de tecnologia projeto a projeto — da landing page que abre no celular até o servidor virtual que configurei em casa.

Em vez de acumular certificado sem prática, sigo o caminho de escolher um problema, construir a solução e documentar tudo: cada repositório meu tem contexto do negócio, tecnologias usadas, prints da tela e passo a passo para rodar.

Busco um estágio em TI onde eu possa contribuir logo de cara e crescer com quem já está na área — trago constância, curiosidade e projeto publicado no GitHub.

Padrão de documentação

Cada projeto tem README completo

Quem avalia não vai rodar o código — vai ler a página do repositório. Por isso todo projeto meu segue o mesmo padrão de documentação:

1

Imagens e GIFs

Print das telas ou GIF curto mostrando o projeto funcionando logo no topo do README.

2

Contexto do negócio

Por que o projeto existe e qual problema real ele resolve, explicado em linguagem simples.

3

Tecnologias utilizadas

Lista das linguagens, frameworks e bancos de dados, com o motivo de cada escolha.

4

Como rodar

Passo a passo dos comandos para qualquer pessoa executar o projeto na própria máquina.
