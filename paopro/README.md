# Pão & Prosa — Projeto de portfólio

Projeto conceitual de informática para uma padaria fictícia. Reúne um site responsivo, identidade visual, uma proposta de automação de encomendas e uma apresentação em slides.

## Como abrir

Abra `index.html` em um navegador. Para a apresentação, abra `slides.html`.
No GitHub Pages, coloque os arquivos da pasta `paopro` em `paopro/` na raiz do repositório. O site ficará em `https://vitorvieira42.github.io/paopro/` e o ZIP para download estará disponível junto dele.

- No computador, navegue pelos slides com as setas do teclado ou os botões.
- No celular, use as setas ou deslize para os lados.
- Use o botão de impressão para imprimir ou salvar os slides como PDF.

Não é necessário instalar dependências. As fontes são carregadas do Google Fonts; sem conexão, o navegador usa fontes alternativas locais.

## Sobre o projeto

- **Site:** página responsiva com apresentação da padaria, cardápio, identidade e proposta digital.
- **Identidade visual:** marca conceitual, paleta e tipografia.
- **Automação:** fluxo demonstrativo de pedido, conferência pela equipe e confirmação. Não há integração real nem coleta de dados.
- **Apresentação:** cinco slides em `slides.html`, com navegação por teclado, toque e impressão.

Todos os produtos, preços e informações da padaria são ilustrativos.
